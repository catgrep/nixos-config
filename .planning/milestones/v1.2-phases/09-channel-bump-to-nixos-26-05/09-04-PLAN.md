## Review feedback incorporated (09-REVIEWS.md, Codex sol run)

- **HIGH — `enabledServices.ser8` was treated as an object.** It is an array (`flake.nix:391`); `jq 'keys'` on it compares indices, so two different service sets of equal length compare identical, and `.sabnzbd` / `.frigate` lookups cannot work. Every service assertion here now goes through `scripts/validation/diff-enabled-services.sh`, which plan 01 created for exactly this, or through an array membership test.
- **HIGH — a dry-run build never executes the Frigate overlay's `postPatch` guard** (`overlays/frigate-tflite-optional.nix:8`), so the old automated verification proved neither that the patch applies nor that the package builds. Task 4 now performs a real package build and then executes the patched imports under the exact filtered `PYTHONPATH` ser8 sets.
- **MEDIUM — `packageInfo` cannot supply the par2 comparison.** It records service packages and the first 50 system packages (`flake.nix:461`), while par2 is embedded only in SABnzbd's wrapper path (`modules/media/sabnzbd.nix:68`). Task 3 evaluates the package attributes directly instead.
- **MEDIUM — the Home Manager warning baseline lives in `.planning/STATE.md:83`** and the old plan only proposed documenting its disappearance in a summary, leaving the authoritative state stale. Task 2 edits STATE.md.
- **MEDIUM — the old Task 1 asked for two commits inside one executor task.** It is now two tasks, so the requested bisection boundary actually exists.
