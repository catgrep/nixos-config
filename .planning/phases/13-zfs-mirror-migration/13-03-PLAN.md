<objective>
Freeze every app service on ser8 per D-02, then create `backup/media-staging` and run the single frozen copy from `/mnt/media` into it (D-03's timing change: quiesce happens before this copy, not after a separate live pass).

Purpose: D-03 collapses the doc's original two-pass design (live copy, then a separate frozen delta-sync) into one clean pass against an already-frozen source — this removes an entire verification category ("drift caused by ongoing writes is expected") and the delta-sync step. The tradeoff is the outage starts here, not at Stage 3.
Output: `backup/media-staging` containing a complete, frozen copy of `/mnt/media`, launched and confirmed via a `systemd-run` transient unit.

This plan implements Leg 1 of the migration's two-leg data flow (D-06): the ext4 source has no ZFS-aware transfer option, so rsync moves it into `backup/media-staging`. Leg 2 (staging -> the new mirror, via `zfs send/recv`) is Plan 13-06.
</objective>
