## Executor note: task count

Five tasks, above the usual three. This is a live-host rollout ladder with two mandatory human gates in the middle of it, and the review's seventh blocker was precisely that the definitive checks sat on the wrong side of the permanent switch. Correcting that ordering requires the sequence: activate reversibly, check, change, activate reversibly again, check again, then commit. Each task is short — the only file this plan edits is `modules/automation/home-assistant.nix`, and the change to it is a deletion or a comment — and splitting the sequence across plan boundaries would leave ser8 sitting in a temporarily activated state between plans, which is worse.
