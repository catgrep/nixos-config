    - Test 3 (content mismatch, small file): two dirs where a file <1 MiB differs by one byte anywhere -> full-hash comparison catches it -> script exits 1.
    - Test 4 (metadata-only mismatch): two dirs with identical content but a differing file mode -> the metadata dry-run catches it even though content sampling would not -> script exits 1.
    - Test 5 (empty source): an empty source directory against an empty destination -> script exits 0 (no files to sample is not an error).
  </behavior>
  <action>
    Create `scripts/sampled-verify.sh` (`#!/usr/bin/env bash`, SPDX header, `set -euo pipefail`). Signature: `sampled-verify.sh <source_dir> <dest_dir> <manifest_file>`. Algorithm: (1) `find "$SOURCE" -type f -print0` to enumerate files; for each, `stat` its size. (2) Files under 1048576 bytes (1 MiB): compute `sha256sum` of the whole file at both source and dest paths, compare directly. (3) Files >=1 MiB: compute N = max(1, size / 1073741824) sample points; for each point i in 0..N-1 compute an offset = i * (size / N) bytes; always include offset 0 (head) and offset (size - 1048576) (tail, clamped to >=0); at each offset read exactly 1 MiB via `dd if="$file" bs=1M skip=$((offset / 1048576)) count=1 status=none`, pipe to `sha256sum`, and compare the same offsets between source and dest (offsets are computed once from the SOURCE file size so they are reproducible at every hop: source, staging, mirror). (4) Separately run `rsync -aHAXn --numeric-ids --itemize-changes --out-format='%i %n' "$SOURCE/" "$DEST/"` (no `-c`/`--checksum` flag -- stat-based only, 100% file coverage, catches size/mtime/mode/uid/gid/type/symlink-target/hardlink-grouping/ACL/xattr differences) and capture its output. (5) Combine: any sample hash mismatch OR any non-empty rsync itemize output means FAIL. Write a timestamped run header plus every difference found (or "PASS -- N files sampled, 0 differences" on success) to `$MANIFEST_FILE`, always -- even on failure, so the manifest is a complete audit trail. Exit 0 only if BOTH the sample comparison and the metadata dry-run found zero differences; exit 1 otherwise -- the exit status is derived from "output was empty", never from a sub-command's own exit code (rsync exits 0 even with differences; do not trust it). Write a companion test script `scripts/sampled-verify.test.sh` implementing the five behavior cases above using local `mktemp -d` fixtures, no network/SSH required. Run `shellcheck` and `shfmt -d` on both files and fix every warning.
  </action>
