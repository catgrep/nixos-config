| Boundary | Description |
|----------|-------------|
| Shared SOPS declarations to two download clients | NZBGet and SABnzbd consume the same administrator and Usenet credentials. |
| LAN nginx to VPN namespace | qBittorrent traffic crosses the local proxy into the NordVPN namespace. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-07 | Information Disclosure | download-client templates | high | mitigate | Preserve placeholders and 0600 runtime file modes; never serialize values. |
| T-08-08 | Elevation of Privilege | qBittorrent nginx/VPN wiring | high | mitigate | Compare firewall, namespace flag, listeners, proxy target, and headers to baseline. |
| T-08-09 | Tampering | atomic qBittorrent config deployment | medium | mitigate | Preserve temporary file, ownership, chmod, and atomic move sequence in evaluated script comparison. |
| T-08-SC | Tampering | package installs | low | accept | No package installation occurs. |
